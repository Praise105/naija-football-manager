# Naija Football Manager

A browser-based football management game inspired by Nigerian club football. You take charge of a club, manage your squad, scout new talent, and chase points in the league.

Features:
- Squad management and player overview
- Match simulation against Nigerian league clubs
- Transfer market for new signings
- Budget, reputation, morale, and fan support tracking
- Save and reset functionality using browser local storage

How to run:
1. Open the project folder in a browser.
2. Double-click `index.html`, or serve it locally with a simple web server.

Example local server:
- `cd naija-football-manager`
- `python -m http.server 8000`
- Open `http://localhost:8000`

Game design:
- Club: Lagos City FC
- League: Nigeria Premier League
- Objective: Build a winning squad and finish as high as possible in the table

Files in this project:
- `index.html` – game layout
- `styles.css` – visual design and responsive styling
- `script.js` – game logic and match simulation

Notes:
- The project is intentionally lightweight and dependency-free.
- It runs directly in the browser without a build step.
